# TP 03: Funciones

## 1. Separacion de pares e impares

Escriba una función separa\_pares\_impares(lista) que reciba una lista de enteros y devuelva dos listas: una con los números pares y otra con los impares, conservando el orden original.

Especificaciones:

- La función debe devolver una tupla (pares, impares).
- No debe modificar la lista original.

Ejemplo de uso:

```python
pares, impares = separa_pares_impares([1, 2, 3, 4, 5, 6])
print(pares)   # [2, 4, 6]
print(impares) # [1, 3, 5]
```

## 2. Funciones con salida verbose

Implemente dos funciones `suma(a, b)` y `resta(a, b)` que devuelvan el resultado de la operación. Ambas deben aceptar un parámetro opcional `debug=False`. Cuando `debug=True`, la función debe imprimir en pantalla un mensaje detallado con:

- El nombre de la operación.
- Los operandos.
- El resultado.

Ejemplo de uso:

```python
suma(2, 3)               # devuelve 5, sin imprimir nada
suma(2, 3, debug=True)   # imprime "[suma] 2 + 3 = 5" y devuelve 5
resta(10, 4, debug=True) # imprime "[resta] 10 - 4 = 6" y devuelve 6
```

## 3.Tabla de valores de una función

Escriba una función `genera_tabla(valores, f)` que reciba:

- `valores`: una lista de números (los valores de `x`).
- `f`: una función de una variable (por ejemplo, `math.sin`, `lambda x: x**2`, etc.).

La función debe devolver una matriz (lista de listas) donde cada fila contenga el par `[x, f(x)]`.

Especificaciones:

- El resultado debe ser una lista de listas, no una lista de tuplas.
- No se debe modificar la lista valores original.

Ejemplo de uso:

```python
import math
tabla = genera_tabla([0, math.pi/2, math.pi], math.sin)
print(tabla)
# [[0, 0.0], [1.5707963267948966, 1.0], [3.141592653589793, 1.2246e-16]]
```

## 4. Función factorial

Implemente una función `factorial(n)` que calcule el factorial de un entero no negativo `n` sin usar `math.factorial`.

Especificaciones:

- Debe aceptar únicamente enteros `n >= 0`.
- Si `n` es negativo o no es entero debe retornar `-1`.

Por convención, `factorial(0) == 1`.

## 5. Búsqueda de números primos

Implemente una función `primos_hasta(n)` que devuelva una lista con todos los números primos entre `2` y `n` (inclusive).

Especificaciones:

- `n` debe ser un entero `>= 2`; en caso contrario, debe retornar `-1`.

El algoritmo debe ser razonablemente eficiente: no es aceptable probar todos los divisores hasta `n-1` para cada número.
